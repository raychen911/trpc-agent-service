# 代码审查

仅审查用户提供的代码、差异或只读仓库内容，不执行命令，不修改文件。

1. 明确变更目标、影响范围和可观察行为。
2. 检查正确性、租户隔离、权限边界、密钥处理、并发与错误恢复。
3. 检查测试是否覆盖公共接口和失败路径。
4. 只报告能够由代码证据支持的问题，按阻断、高、中、低排序。
5. 每个问题包含位置、原因、影响和最小修复建议；没有问题时明确说明剩余测试风险。

如果代码来自 MCP，只使用 Agent 已授权的只读仓库工具。创建分支、修改文件、提交、合并等操作不属于本 Skill。
