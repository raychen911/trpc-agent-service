# 第八阶段成果记录（US8 收口，FR-036，SC-011）

## 1. 框架复用 vs 平台新增对照

**直接复用 tRPC-Agent-Python（官方 SDK，未修改）**：
- 官方 Runner（`trpc_agent_sdk.runners.Runner`）执行 Agent 与 Session 管理
- 官方 OTel instrumentation：ProxyTracer 惰性解析全局 provider，平台在进程级
  单例 bootstrap 安装 TracerProvider 后，官方 Runner span 自动嵌套在平台根 span 下
- OpenTelemetry SDK（1.44.0）：TracerProvider、SimpleSpanProcessor、OTLP HTTP exporter

**平台新增模块（第八阶段）**：
- 边界与关联：`observability/context.py`（W3C 关联、14 阶段分类、scope/trace digest）
- 脱敏：`observability/sanitizing.py`（20 键属性白名单、fail-closed 适配器）
- 采样与缓冲：`observability/sampling.py`（关键全保留/普通 10%/ceiling 25%）、
  `observability/buffer.py`（有界优先级缓冲、CriticalDiagnosticSummary）
- 指标：`observability/metrics.py`（9 指标、标签域校验）
- 健康与告警：`observability/health.py`（5 角色矩阵、路径聚合）、
  `observability/alerts.py`（指纹去重、CAS 状态机）
- 发布与回滚：`operations/release.py`（有界状态机、command_id 幂等、CAS/fence）、
  `operations/routing.py`（fail-closed 路由解析、ExecutionConfigPin）、
  `operations/gates.py`（硬/质量门槛）、`governance/hard_gate.py`（持久 enforcement point）
- 容量：`operations/capacity.py`（正式场景、确定性负载、双门禁）
- 排空与部署：`operations/drain.py`（forward-only 排空、WorkerPool fence 接管）、
  `operations/deployment.py`（LocalObservableOverlay）、`deploy/local-observable/`
- 故障演练：`operations/fault_exercise.py`（4+ 项可重复演练）
